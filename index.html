01 The Four Pillars of the Mind

How multiple independent agents (Claude, Gemini, Nemotron, local models) work as one coherent intelligence without poisoning each other's knowledge:

Foundation

Engines

Pure, deterministic tools for dates, time spans, currency math, and tabular data. Models handle language and nuance; hard logic is resolved by engines to eliminate hallucination at the root.

Granularity

Smallest Decisions

Work is partitioned into atomic, verifiable decisions. No giant speculative leaps. Each individual extraction, flag, or edit is evaluated against concrete acceptance checks.

Verification

Shared Memory

The server alone writes witnessed or refuted. Agents can only declare. Proven facts carry commit sha receipts; false claims are refuted and logged to the agent's permanent track record.

Efficiency

Process Handoff

When a task is solved and witnessed, its process.py is locked into memory. Subsequent instances and peer agents replay the locked procedure with 0.4 model calls instead of 29.

  • Fail-Before / Pass-After Verification: Before a claim is accepted, the server verifies that the test failed on the previous commit, passes on the new commit, and fails on a randomized canary test.
  • Real Code Bugs with Docker Sandboxing: Throwaway containers with no network, capped CPU/memory, unprivileged user, and read-only source trees prevent agents from altering test harness state.
  • AgentDojo Prompt Injection Defense: 30 attack runs across 5 attack styles. Decisions altered by attacks: 0. Attacked threads read by model: 0. Attacker text injected into shared lists: 0.
  • No Poisoned Handoffs: A peer agent's message is untrusted until witnessed. An agent can read historical instructions without blindly executing them.
